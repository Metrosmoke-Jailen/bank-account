# Bank Account

This project is a Python program that simulates a basic bank account using object-oriented programming principles.

## Features
- Create bank accounts with a name, account number, and balance
- Deposit and withdraw money
- Apply monthly interest
- Print formatted bank statements
- Handle overdraft fees

## Technologies Used
- Python 3
- Object-Oriented Programming (OOP)
